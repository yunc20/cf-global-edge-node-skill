**1/7**
0 元、不用信用卡、不用 VPS,自己在 Cloudflare 上搭了一个节点,刷推、看 YouTube 很稳,比几万人共用的机场节点好多了。免费版每天 10 万次请求,一个人根本用不完。完整教程和踩坑记录都整理好了 🧵

**2/7**
原料就三样:
① Cloudflare 免费账号
② DNSHE 免费域名(us.ci 后缀,1 年期,到期前 180 天内可免费续)
③ cmliu/edgetunnel 的 _worker.js,只从原作者仓库下载,并核对 SHA-256。网上的魔改版有偷 UUID 的。

**3/7**
最关键的一点:别用 workers.dev / pages.dev 当节点地址,大陆网络下经常全部超时。正确做法是用 Pages 部署,在 DNSHE 加一条子域名 CNAME 指过去。几分钟就生效,不用把整个域名迁到 CF。

**4/7**
我们踩过的坑:
· DNSHE 不收临时邮箱,用 Outlook 可以
· 领域名前必须先绑 TOTP 两步验证
· 项目名别带 proxy、vpn、tunnel,起个 notes-blog 这样的普通名字
· wrangler 用 Node 22,项目里建个空的 node_modules 文件夹

**5/7**
优选 IP:非 443 端口(2053 / 2083 / 2087 / 8443)的反代入口最好用。要用 AI 就别选香港,台、日、新加坡加美国最合适。服务器上测通了,手机上也可能超时:我们 9 个节点里有 3 个超时,换成备用的就好了。

**6/7**
老实说说风险:
· CF 条款不让拿它当代理。自己用是自担风险,分享或做机场最容易被封
· 出口是 CF 的 IP,不是家宽
· 面板界面是远程加载的,少登录
· Clash 订阅要经过第三方转换,转换方能看到域名和入口 IP
